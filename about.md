# GDPS Connect

GDPS Connect is a Geode mod project by Zeer.

The goal is to let players save multiple GDPS profiles and switch between them using a controlled game restart.

## Current status

This repository currently contains the initial Geode project scaffold. The profile UI, endpoint integration, and restart flow are not implemented yet. Do not treat this version as a working GDPS switcher.

## Planned features

- Save and manage multiple GDPS profiles.
- Validate profile addresses before saving.
- Select a profile to use.
- Apply the selected profile and restart Geometry Dash when required.
- Support Windows and Android builds, subject to Geode SDK/platform compatibility.
